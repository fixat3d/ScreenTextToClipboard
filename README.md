# ScreenTextToClipboard
Copies text off your screen and puts it into your copy and paste clipboard. When the program runs just hit enter, the program will copy text, then paste ctrl-v where ever you need.

This project needs
tesseract-ocr
https://download.cnet.com/tesseract-ocr/3000-2067_4-78705431.html

pytesseract
link here: https://pypi.org/project/pytesseract/
